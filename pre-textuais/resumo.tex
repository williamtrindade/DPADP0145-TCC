\resumo{
    A Arquitetura Limpa tem como objetivo oferecer um modelo para desenvolver aplicações manuteníveis e testáveis, todavia, a sua aplicação prática em frameworks de desenvolvimento web como o Laravel, partindo de uma estrutura Model-View-Controller (MVC), carece de documentação detalhada na literatura atual. Este trabalho visa preencher essa lacuna, apresentando um estudo de caso focado no processo de refatoração de uma API REST Laravel MVC, para faze-la aplicar os conceitos da arquitetura limpa. 
    Será detalhada a reestruturação do código em camadas independentes – Entidades, Casos de Uso, Adaptadores de Interface e Frameworks/Drivers – mostrando a aplicação dos princípios da Arquitetura Limpa. 
    O resultado esperado é um guia prático que ilustre as etapas, decisões de design e a organização final do código, servindo como referência para desenvolvedores que buscam implementar esta arquitetura em projetos de API em Laravel.
}

\abstract{
    Clean Architecture aims to offer a model for developing maintainable and testable applications. However, its practical application in web development frameworks like Laravel, starting from a Model-View-Controller (MVC) structure, lacks detailed documentation in current literature. This work aims to fill this gap by presenting a case study focused on the refactoring process of a Laravel MVC REST API to apply Clean Architecture concepts.
    The code restructuring into independent layers – Entities, Use Cases, Interface Adapters, and Frameworks/Drivers – will be detailed, demonstrating the application of Clean Architecture principles.
    The expected result is a practical guide that illustrates the steps, design decisions, and final code organization, serving as a reference for developers seeking to implement this architecture in Laravel API projects.
}
